# مُدار (Modar) — برنامج إدارة محلات وكافيهات البلايستيشن

**مُدار برنامج كمبيوتر بيدير محل البلايستيشن كله: الغرف والوقت والكافيه والكاشير والموظفين والحسابات. وبيشتغل من غير إنترنت خالص.**

🌐 الموقع: **[ats.enterprises](https://ats.enterprises/gaming)**
⬇️ التحميل: **[آخر نسخة من هنا](https://github.com/AbdoHendawy/modar-releases/releases/latest)**
🎁 تجربة مجانية **7 أيام** بكل المميزات، ومن غير بطاقة ائتمان.

---

## مناسب لمين؟

- محلات وكافيهات البلايستيشن (PS4 / PS5)
- صالات الجيمينج
- الـ Coworking Spaces وأي نشاط بيتحاسب بالساعة

## المميزات

| | |
|---|---|
| 🎮 **الغرف والجلسات** | سعر ساعة سنجل ومالتي لكل غرفة، جلسة مفتوحة أو محددة، زيادة وقت، نقل جلسة، مقدّم، خصم مع سبب، وتنبيه لما الوقت يخلص |
| ⚡ **انقطاع الكهربا** | الجلسات بترجع زي ما كانت، ووقت الانقطاع بيتخصم من حساب العميل تلقائي |
| 🧾 **الكاشير** | طلبات الكافيه على الجلسة، بيع سريع، وإيصال حراري 80mm |
| 📦 **المخزون** | خصم تلقائي مع البيع، صفحة النواقص، واستيراد المنتجات من Excel |
| 💰 **درج الكاش** | بيحسب المفروض يكون في الدرج كام لحظة بلحظة، وتسليم الوردية بيتسجل |
| 👥 **الموظفين** | PIN لكل موظف، صلاحيات، حضور، مرتبات وسُلف |
| 📊 **التقارير** | الإيراد حسب الغرفة، أكتر المنتجات مبيعًا، المصاريف، وتصدير PDF بالعربي |
| 📺 **الشاشات** | تشغيل وإطفاء شاشة الغرفة مع الجلسة: LG وSamsung وAndroid TV وShelly وTasmota وWake-on-LAN |
| 🔐 **الأمان** | سجل لكل عملية (مين عمل إيه وإمتى)، ونسخ احتياطي واسترجاع بضغطة |

## التسطيب

1. نزّل ملف `.exe` من **[آخر نسخة](https://github.com/AbdoHendawy/modar-releases/releases/latest)**.
2. شغّله. لو ويندوز طلّع رسالة "Windows protected your PC"، دوس **More info** وبعدها **Run anyway**.
3. اعمل حساب المدير، وضيف غرفك وأسعارك، وابدأ.

**المتطلبات:** Windows 10 أو 11 (64-bit). البرنامج بيحدّث نفسه تلقائي لما يلاقي إنترنت.
